# Project Phoenix - AI Engineering Guidelines

## Mission

Build a production-inspired Infrastructure Platform for deploying, monitoring, securing, and operating applications.

## Principles

- Small commits.
- Production-ready code.
- No hardcoded secrets.
- Docker-first development.
- Clean architecture.
- Documentation for every feature.
- Security by default.
- Explain major design decisions.

## Tech Stack

Frontend:
- Next.js
- TypeScript
- Tailwind CSS

Backend:
- Go

Infrastructure:
- Docker
- Docker Compose
- Nginx
- PostgreSQL
- Redis
- Prometheus
- Grafana

Future:
- Kubernetes
- Terraform
- AWS
- AI Assistant

## Rules

Never generate unnecessary code.

Never install packages without approval.

Prefer readability over cleverness.

Keep changes focused on the requested task.

Always explain why changes were made.
